# 📊 MS Excel Projects

A curated collection of Microsoft Excel projects developed to strengthen practical data analysis skills through real-world business scenarios and analytical problem-solving.

## 📌 About This Repository

This repository contains Excel-based projects covering different business domains and datasets. Each project focuses on applying Excel for data cleaning, analysis, reporting, and dashboard creation using industry-relevant techniques.

The objective is to demonstrate practical analytical thinking, problem-solving abilities, and proficiency in Excel while working with structured datasets.

## 🚀 Key Skills Demonstrated

- Data Cleaning & Preparation
- Data Validation
- Sorting & Filtering
- Conditional Formatting
- Pivot Tables
- Pivot Charts
- Lookup Functions (VLOOKUP, XLOOKUP, INDEX-MATCH)
- Logical Functions
- Text & Date Functions
- Statistical Functions
- Dynamic Reports
- Interactive Dashboards
- Business Data Analysis

## 📁 Repository Structure

Each project includes one or more of the following:

- Excel Workbook (.xlsx)
- Business Dataset
- Data Analysis
- Reports
- Dashboards (where applicable)
