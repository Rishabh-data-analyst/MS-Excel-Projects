# Microsoft Excel Practice Repository

## Overview

This repository showcases my hands-on Excel practice focused on developing the analytical and problem-solving skills required for a Data Analyst role. The exercises are designed around realistic business scenarios and cover a wide range of Excel concepts used in data cleaning, analysis, reporting, and decision-making.

The objective of this repository is to strengthen formula-writing skills, improve logical thinking, and build confidence in solving business problems using Microsoft Excel.

## Practice Approach

The exercises focus on solving practical business problems rather than memorizing formulas. Each workbook contains structured datasets and analytical questions that require selecting the appropriate Excel functions, combining multiple formulas when necessary, and interpreting the results accurately.

The emphasis is on developing an analytical mindset that can be applied to real-world business data.

---

## Excel Version Compatibility

This repository was created using **Microsoft Excel 2019**. Therefore, all solutions are compatible with Excel 2019 and rely on widely supported functions.

I also understand the purpose and use cases of modern Microsoft 365 functions such as **XLOOKUP, FILTER, SORT, UNIQUE, LET,** and **LAMBDA**, and I continue expanding my knowledge of the latest Excel features to stay aligned with current industry practices.
